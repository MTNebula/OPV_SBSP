# OPV_SBSP
Organic Photovoltaics for Space Based Solar Power

This is a simple command-line application written in Python. It includes doing a Monte-Carlo Simulaiton

## Features

- Reading in Bases
- Add two numbers.
- Subtract the second number from the first number.

## How to Run

1. Make sure you have Python installed on your machine.
2. Navigate to the project directory.
3. Run the application using the command:

    ```sh
    python main.py
    ```

## Testing

To run the tests, navigate to the `tests` directory and run:

    ```sh
    python -m unittest test_utils.py
    ```
